# S37 — Plytka kopia TABLICY przez spread `[...arr]` (2026-08-03)

**Koncept:** `[...arr]` tworzy NOWA tablice tylko na najwyzszym poziomie. Kazdy element, ktory sam jest obiektem, jest kopiowany jako REFERENCJA — mutacja w "kopii" widoczna jest tez w oryginale. Ten sam mechanizm co spread obiektu (S36), przeniesiony na tablice.

**Format:** BUG-HUNT (znajdz linie ktora klamie) · **Fabula:** kolejka zamowien kawy "CoffeeQueue"

## Starcie 1 — kopia kolejki zamowien

```js
const kolejkaBazowa = [
  { klient: "Ala", napoj: "latte", gotowe: false },
  { klient: "Tom", napoj: "espresso", gotowe: false }
];

const kolejkaKopia = [...kolejkaBazowa];

console.log(kolejkaBazowa === kolejkaKopia);
console.log(kolejkaBazowa[0] === kolejkaKopia[0]);
```

**Zanim przewiniesz: przewidz obie linie.**

## Starcie 2 — funkcja oznaczajaca pierwsze zamowienie jako gotowe

```js
function oznaczPierwszyGotowy(kolejka) {
  const kopiaBezpieczna = [...kolejka]; // "bezpieczna kopia zanim zmienimy"
  kopiaBezpieczna[0].gotowe = true;
  return kopiaBezpieczna;
}

const kolejkaOryginal = [
  { klient: "Ala", napoj: "latte", gotowe: false },
  { klient: "Tom", napoj: "espresso", gotowe: false }
];

const nowaKolejka = oznaczPierwszyGotowy(kolejkaOryginal);

console.log(kolejkaOryginal[0].gotowe);
console.log(nowaKolejka[0].gotowe);
console.log(kolejkaOryginal === nowaKolejka);
```

**Pytanie:** jedna linia w tym kodzie klamie — ktora, i dlaczego kopia nie jest tak bezpieczna, jak twierdzi komentarz?

## Verified (node, uruchomione przed publikacja)

```
Starcie 1: false / true
Starcie 2: true / true / false
```

Spread tablicy nie sklonowal elementow — oba obiekty-zamowienia pod indeksem 0 wskazuja to samo miejsce w pamieci. Naprawa: `structuredClone(arr)`, `JSON.parse(JSON.stringify(arr))`, albo `arr.map(el => ({...el}))`.

## Quiz

1. `const a = [1, { x: 1 }]; const b = [...a];` — ile wynosi `a === b`, a ile `a[1] === b[1]`? → `false` / `true` (spread kopiuje tylko poziom 1)
2. Dwa sposoby na prawdziwie niezalezna kopie tablicy z obiektami? → `structuredClone(arr)`, `JSON.parse(JSON.stringify(arr))`
3. Czemu `kopiaBezpieczna[0].gotowe = true` zmienia tez `kolejkaOryginal`? → `kopiaBezpieczna[0]` i `kolejkaOryginal[0]` to ten sam obiekt w pamieci

## Karta (SM-2)

**Q:** Co dokladnie kopiuje `[...arr]`, a czego NIE kopiuje?
**A:** Plytka kopia: nowa tablica na poziomie 1 (`arr === [...arr]` → false), ale elementy-obiekty ida jako referencje (`arr[0] === [...arr][0]` → true, gdy element to obiekt). Mutacja elementu w kopii zmienia tez oryginal.

---
*Puenta: `[...arr]` to blizniak `{...obj}` z wczoraj — inna skorupa, ten sam falszywy komfort: srodek nadal jest wspolny z oryginalem. Dokladnie ten wzorzec czyha w kodzie, ktory kopiuje tablice rekordow "na wszelki wypadek" przed modyfikacja jednego z nich.*
