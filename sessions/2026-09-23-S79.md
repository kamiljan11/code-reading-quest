# S79 — Arrays: the line between "a copy of the list" and "the same place"

**Concept:** an array does not hold objects, it holds references to them. `[...list]` gives you a new array with the same tenants — and several array methods do not return a copy at all, they reorder or cut the original. The method name does not tell you which.

**Story:** the "Vitinn" tool router receives a list of `tool_calls` from a model and, before executing anything, "just tidies it up".

## Round 1

```js
const ODPOWIEDZ = [
  { tool: "search", p: 10 },
  { tool: "write",  p: 9  },
  { tool: "search", p: 2  },
];

const surowe = ODPOWIEDZ;
const kopia = [...ODPOWIEDZ];

console.log("1)", surowe === ODPOWIEDZ, kopia === ODPOWIEDZ);

kopia[0].p = 99;
console.log("2)", ODPOWIEDZ[0].p);

const priorytety = [10, 9, 2, 100];
console.log("3)", priorytety.sort());
console.log("4)", priorytety);

const nazwy = ODPOWIEDZ.map(x => x.tool);
console.log("5)", nazwy.indexOf("write"), nazwy.indexOf("plan"));

const wybrane = ODPOWIEDZ.filter(x => x.p > 5);
console.log("6)", wybrane.length, ODPOWIEDZ.length);

const usuniete = ODPOWIEDZ.splice(1, 1);
console.log("7)", usuniete, ODPOWIEDZ.length);

const braki = [NaN, undefined];
console.log("8)", braki.includes(NaN), braki.indexOf(NaN));

console.log("9)", [1,2,3].map(n => { if (n === 2) return; return n * 2; }));
```

## Round 2 — code review

The PR describes this helper as "a pure read of the highest priority from the call list".

```js
const BUFOR = [{ tool: "a", p: 1 }, { tool: "b", p: 3 }];

function najwazniejsze(lista) {
  return lista.sort((x, y) => y.p - x.p)[0];
}

console.log("10)", najwazniejsze(BUFOR).tool);
console.log("11)", BUFOR.map(x => x.tool).join(","));

const pusta = [];
console.log("12)", najwazniejsze(pusta));
try {
  console.log("13)", najwazniejsze(pusta).tool);
} catch (e) {
  console.log("13)", e.constructor.name + ":", e.message);
}
```

## Verified

Run locally with `node v22.23.2` before the answer key was written.

```
1) true false
2) 99
3) [ 10, 100, 2, 9 ]
4) [ 10, 100, 2, 9 ]
5) 1 -1
6) 2 3
7) [ { tool: 'write', p: 9 } ] 2
8) true -1
9) [ 2, undefined, 6 ]
10) b
11) b,a
12) undefined
13) TypeError: Cannot read properties of undefined (reading 'tool')
```

Review verdict: the comparator is correct and the returned element really is the highest priority one. The helper nevertheless does three things its name does not promise — it permanently reorders the caller's array (line 11), it returns `undefined` for an empty list instead of throwing or returning a neutral value, and because of that it moves the explosion to the consumer reaching for `.tool`, two layers away from the cause.

## Quiz

1. Line 6 prints `2` for a three-element list. Which line decided that, and what would line 6 print if `kopia` had been built with `ODPOWIEDZ.map(x => ({ ...x }))`?
   **Key:** `kopia[0].p = 99` — the shallow copy raised the original's `p` from 10 to 99. The count `2 3` would be unchanged either way (10 and 9 both pass `> 5`); what changes is line 2, which would print `10` instead of `99`.
2. Python's `lista[:]` has the same problem. Which standard-library function fixes it, and why is `structuredClone` not a full equivalent?
   **Key:** `copy.deepcopy`. `structuredClone` copies deeply but throws `DataCloneError` on functions, class instances with methods, Proxies and DOM objects.
3. Fix `najwazniejsze` with one change inside the body, no new lines. Does line 13 still throw?
   **Key:** `return [...lista].sort((x, y) => y.p - x.p)[0]` (or `lista.toSorted(...)[0]`). It removes the mutation but not the empty-list behaviour — `[0]` of an empty array is still `undefined`, so line 13 throws the same `TypeError`.

## Card

**Front:** Which array methods change the array they were called on?
**Back:** MUTATE: `sort`, `reverse`, `splice`, `push`, `pop`, `shift`, `unshift`, `fill`, `copyWithin`. LEAVE THE SOURCE ALONE: `map`, `filter`, `slice`, `concat`, `flat`, `join`, spread `[...arr]`, plus `toSorted` / `toReversed` / `toSpliced` / `with`. Trap: `sort` and `reverse` return an array, so they look like copying methods — but it is the same array. Second trap: `[...arr]` copies only the first level.

## Takeaway

The helper is named like a read and leaves behind a reordered list belonging to the caller. That is the class of pull request you approve every day: correct result, correct comparator, and a side effect that surfaces two layers later.
