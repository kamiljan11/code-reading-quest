# S91 - Functions: what a function really returns, and the forged webhook that reached the ledger

**Concept:** a function returns exactly what stands after `return` on the same line, and `async` turns every result into a promise. So `if (!check(req))` with an async `check` never rejects anything, `(code) => { code }` returns nothing, and `return` with an object literal on the next line returns `undefined`.

**Story:** a payment gateway in Akureyri receives webhooks from a partner; each one carries a signature in the `x-signature` header, and the handler books only correctly signed events. An AI assistant opened a PR titled "refactor: async + shorter arrows, logic unchanged". Tests on real webhooks stayed green. A week later the accountant finds a 5000 payment in the ledger that the partner never sent, and the partner asks why the gateway's responses are empty. (Pure node simulation; the signature check is simplified to a string comparison, the real one is an HMAC.)

## Round 2 - the handler on two webhooks, a real one and a forged one (separate file)

```js
// Starcie 2 — ten sam odbiornik, dwa webhooki: prawdziwy i podrobiony.
const SEKRET = "s3kr3t";
async function podpisOk(req) {
  return req.headers["x-signature"] === `${SEKRET}:${req.body.id}`;
}
const odpowiedz = (kod) => { kod };
const ksiega = [];

// + PO PR: handler w node `Code` / Express
function obsluz(req) {
  if (!podpisOk(req)) return odpowiedz(401);
  ksiega.push(`${req.body.id}:${req.body.kwota}`);
  return odpowiedz(200);
}

// Poprawka z review
async function obsluzPoprawka(req) {
  if (!(await podpisOk(req))) return { kod: 401 };
  ksiega.push(`${req.body.id}:${req.body.kwota}`);
  return { kod: 200 };
}

const zdarzenia = [
  { headers: { "x-signature": "s3kr3t:P-1" }, body: { id: "P-1", kwota: 1200 } },
  { headers: { "x-signature": "zgaduje" }, body: { id: "P-7", kwota: 5000 } },
];

console.log("5)", zdarzenia.map((r) => obsluz(r)));
console.log("6)", ksiega.join(","));
ksiega.length = 0;

(async () => {
  const wyniki = [];
  for (const r of zdarzenia) wyniki.push(await obsluzPoprawka(r));
  console.log("7)", wyniki);
  console.log("8)", ksiega.join(","));
})();
```

Diagnosis: (a) `async` added to `podpisOk` with no `await` at the call site; `(kod) => { kod }` instead of a function with `return { kod, ok }`; `return` moved to its own line above the literal. (b) `async` is the dangerous one: a promise is an object, so `!podpisOk(req)` is always `false` and the forged P-7 for 5000 lands in the ledger (line 6). Tests with real webhooks cannot catch it, because real webhooks are supposed to pass anyway. (c) `if (!(await podpisOk(req)))` inside an async handler (lines 7-8 show the effect), `const odpowiedz = (kod) => ({ kod, ok: kod < 300 });`, and `return { kwota: req.body.kwota };` on one line.

## Quiz

1. What does `const f = () => { ok: true }` return, and why?
   **Key:** `undefined`. The brace after `=>` opens a function body (a block), `ok:` is a label, and the block has no `return`. An object literal needs parentheses: `() => ({ ok: true })`.
2. Why does `if (!check(req)) return 401` let every request through when `check` is `async`?
   **Key:** an async function always returns a promise, a promise is an object, objects are truthy, so `!promise` is `false`. It needs `await`.
3. What does a function return when `return` stands alone on a line and the object literal is on the next one?
   **Key:** `undefined`. Automatic semicolon insertion ends the statement right after `return`; the brace below becomes a separate, dead block.

## Card

**Front:** `async function ok(req) { return false }` and then `if (!ok(req)) reject()`. Does `reject()` run?
**Back:** No. An async function returns a `Promise`, an object is truthy, so `!ok(req)` is `false`. You need `if (!(await ok(req)))` inside an async function.

## Takeaway

Webhook work starts with one function: signature verification. Looking for the `await` on the other side of every newly added `async`, and asking what every braced arrow returns, catches in review the hole through which someone else's payment enters the books.
