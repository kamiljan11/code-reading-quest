# S95 - Loops: what `break` exits, what `continue` skips, and whether the loop runs at all

**Concept:** `break` ends the NEAREST `switch` or loop, so a `break` inside a `case` stops only the `switch` while the loop keeps going. `continue` always belongs to the loop, and in a `do...while` it jumps straight to the condition, skipping the rest of the body. `while` checks its condition BEFORE the first pass (an empty cursor at start means zero passes), and `i <= length` reads one element past the end.

**Story:** the "Saevar" ferry runs from Arskogssandur to Hrisey and has 4 places. An n8n workflow takes bookings from a webhook, a `Code` node counts the next crossing, and the captain gets an SMS. A nightly import pulls bookings from a cursor-paginated API. An AI assistant opened a PR: "ifs replaced with a switch, no logic change". Since then the captain gets a "5/4" report that includes tomorrow's booking, and the import either fetches nothing or spins until its retry limit. (Pure node simulation; `$input.all()` is a plain `items` array, the API is an object.)

## Round 1 - import loops (what if)

```js
// Prom "Saevar" na Hrisey: node Code w n8n ("Run Once for All Items"), symulacja w czystym node.
const items = [
  { json: { id: "R1", osoby: 2 } },
  { json: { id: "R2", osoby: 4 } },
  { json: { id: "R3", osoby: 1 } },
  { json: { id: "R4", osoby: 3 } },
];
// API rezerwacji stronicuje kursorem; pierwsza strona = brak kursora.
const STRONY = {
  start: { dane: ["A", "B"], next: "p2" },
  p2:    { dane: [],         next: "p3" },   // pusta strona w srodku
  p3:    { dane: ["C"],      next: "" },
};
const pobierz = (k) => STRONY[k ?? "start"];

let suma = 0;
try {
  for (let i = 0; i <= items.length; i++) suma += items[i].json.osoby;
} catch (e) { console.log("1)", suma, e.message); }

let k1; const a = [];
while (k1) { const s = pobierz(k1); a.push(...s.dane); k1 = s.next; }
console.log("2)", a.length, a.join(",") || "-");

let k2; const b = [];
do { const s = pobierz(k2); b.push(...s.dane); k2 = s.next; } while (k2);
console.log("3)", b.length, b.join(",") || "-");

let k3; let proby = 0; const c = [];
do {
  proby++;
  const s = pobierz(k3);
  if (s.dane.length === 0) continue;   // "pusta strona - pomin"
  c.push(...s.dane);
  k3 = s.next;
} while (k3 && proby < 5);
console.log("4)", proby, c.join(","));
```

## Round 2 - the "ifs replaced with a switch" PR (separate file)

```js
// Starcie 2 - osobny plik: PR od asystenta AI "if-y zamienione na switch, logika bez zmian".
// Prom ma 4 miejsca. Webhook wpuszcza znacznik STOP: za nim sa rezerwacje na JUTRO.
const items = [
  { json: { id: "R1", status: "ok",        osoby: 2 } },
  { json: { id: "R2", status: "anulowana", osoby: 4 } },
  { json: { id: "R3", status: "STOP",      osoby: 0 } },
  { json: { id: "R4", status: "ok",        osoby: 3 } },
];

function przed(items) {
  let miejsca = 0; const out = [];
  for (const it of items) {
    if (it.json.status === "anulowana") continue;
    if (it.json.status === "STOP") break;
    miejsca += it.json.osoby;
    out.push(it.json.id);
  }
  return `${miejsca}/4 | ${out.join(",")}`;
}

function po(items) {
  let miejsca = 0; const out = [];
  for (const it of items) {
    switch (it.json.status) {
      case "anulowana": continue;
      case "STOP": break;
      default: miejsca += it.json.osoby;
    }
    out.push(it.json.id);
  }
  return `${miejsca}/4 | ${out.join(",")}`;
}

console.log("5)", przed(items));
console.log("6)", po(items));
```

## Verified

Run with `node v22.22.0` and re-checked with `node v24.21.0` on the local machine (each round as a separate file) before the answer key was written.

```
1) 10 Cannot read properties of undefined (reading 'json')
2) 0 -
3) 3 A,B,C
4) 5 A,B
```

```
5) 2/4 | R1
6) 5/4 | R1,R3,R4
```

Diagnosis: line 6: `break` in `case "STOP"` ends only the `switch`, so `out.push` records the STOP marker R3 and the loop goes on to R4, which is tomorrow's booking: 5 people for a ferry with 4 places. `continue` for the cancelled booking still works, because `continue` belongs to the loop. (a) With a `petla:` label before the `for` and `break petla;` the line prints `6b) 2/4 | R1` (checked separately), the same as before the PR. (b) Without `&& proby < 5` the loop never ends: on the empty page `continue` jumps to the condition and skips `k3 = s.next`, so the cursor stays on the empty `p2` forever and the `Code` node hangs until the execution timeout. (c) A `do...while` fetches the first page without a cursor, so line 2 would print `3 A,B,C` like line 3; line 3 got through the empty `p2` because it has no `continue` and `k2 = s.next` always runs. Line 1 managed to sum all four elements before the fifth pass (`i = 4`) threw. Fix: `if (it.json.status === "STOP") break;` before the `switch` (or a labelled break), move the cursor before any `continue`, and use `i < items.length` or `for...of`.

## Quiz

1. What does `break` do inside a `case` of a `switch` that sits in a `for...of` loop?
   **Key:** It ends only the `switch`; the loop runs the lines below it and takes the next element. To leave the loop use a labelled break or `if (...) break;` before the `switch`.
2. How many times does the body of `while (k) { ... }` run with `let k;`, and how many times `do { ... } while (k)`?
   **Key:** `while`: zero; `do...while`: once.
3. How many passes does `for (let i = 0; i <= arr.length; i++)` make for 4 elements, and what does the last one get?
   **Key:** Five; the last reads `arr[4]`, which is `undefined`, so `.json` throws a TypeError.

## Card

**Front:** A `switch` sits inside a `for...of` loop and has `case "STOP": break;`. Does the loop stop?
**Back:** No. `break` ends the nearest `switch` and the loop continues. To leave the loop use a labelled break or `if (...) break;` before the `switch`.

## Takeaway

n8n is the most frequent requirement in automation job posts, and in a `Code` node it mostly means two loops: over `$input.all()` and over API pages. Asking "what exactly does this `break` leave?" and "which lines does this `continue` skip?" keeps you from sending a captain a report for five people on a four-place ferry, or leaving a workflow fetching the same empty page until it times out.
