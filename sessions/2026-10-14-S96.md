# S96 - Arrays: `slice` excludes the end, `reduce` without an initial value starts from an object, and an array pasted into a string

**Concept:** `slice(start, end)` does NOT include `end`, so `slice(i, i + 3 - 1)` makes batches of two and drops every third id. `push(array)` appends ONE element (the whole array); only `flatMap` or `push(...array)` flattens. `reduce` without an initial value uses the first ELEMENT as the accumulator (object + number = string), with one element it never calls the callback, and with an empty array it throws a `TypeError`. An array inside a template string calls `join(",")`, which turns `null` and `undefined` into empty slots, and `Math.min()` with no arguments returns `Infinity`.

**Story:** the "Gistihus Stykkisholmur" guesthouse has seven rooms and checks their availability with a partner over a REST API. The bulk endpoint `GET /availability?ids=...` accepts at most three ids per request and answers in pages. An n8n `Code` node splits the ids into batches, collects the pages and sums the prices for the owner's report. An AI assistant opened a PR: "shorter query building and cheapest offer, no logic change". Since then the report shows `[object Object]25080`, two rooms are never checked, and the partner receives requests with empty ids. (Pure node simulation; the API is an array of pages.)

## Round 1 - batches and pages (find the bug)

```js
// Pensjonat "Gistihus Stykkisholmur": klient REST API dostepnosci pokoi (node Code w n8n, symulacja w czystym node).
// Endpoint zbiorczy GET /availability?ids=... przyjmuje maksymalnie 3 id na zapytanie.
const ids = ["H1", "H2", "H3", "H4", "H5", "H6", "H7"];
const ROZMIAR = 3;
const paczki = [];
for (let i = 0; i < ids.length; i += ROZMIAR) paczki.push(ids.slice(i, i + ROZMIAR - 1));
console.log("1)", paczki.length, JSON.stringify(paczki));

// Odpowiedz API przychodzi stronami; kazda strona ma tablice items.
const strony = [
  { items: [{ id: "A", cena: 100 }] },
  { items: [] },
  { items: [{ id: "B", cena: 250 }, { id: "C", cena: 80 }] },
];
const wszystkie = [];
wszystkie.push(strony.map((s) => s.items));
console.log("2)", wszystkie.length, wszystkie[0].length);
const plaskie = strony.flatMap((s) => s.items);
console.log("3)", plaskie.length, plaskie.map((o) => o.id).join(""));

const suma = (lista) => lista.reduce((acc, x) => acc + x.cena);
console.log("4)", suma(plaskie));
console.log("5)", suma([{ id: "A", cena: 100 }]));
try { console.log("6)", suma([])); } catch (e) { console.log("6)", e.name, e.message); }
```

## Round 2 - the "shorter query and cheapest offer" PR (separate file)

```js
// Starcie 2 - osobny plik: PR od asystenta AI "krotsze budowanie query i najtansza oferta, logika bez zmian".
function query(ids) {
  return "ids=" + ids.filter((id) => id).map(encodeURIComponent).join(",");
}
function najtansza(oferty) {
  return oferty.length ? Math.min(...oferty.map((o) => o.cena)) : null;
}

// --- po PR ---
const query2 = (ids) => `ids=${ids}`;
const najtansza2 = (oferty) => Math.min(...oferty.map((o) => o.cena));

const ids = ["H1", null, "H 3", undefined];   // formularz w n8n zostawil puste pola
console.log("7)", query(ids));
console.log("8)", query2(ids));
console.log("9)", najtansza([]), najtansza2([]));
console.log("10)", najtansza([{ cena: "250" }, { cena: 80 }]), najtansza2([{ cena: "250" }, { cena: 80 }, {}]));
```

**Question:** give all ten output lines (each round as a separate file). Then: (a) which two ids never get into a batch, and which single number in the `slice` line fixes it; (b) what lines 4, 5 and 6 print when `reduce` gets a second argument `0`; (c) for which inputs each of the two PR changes behaves like the original.

## Verified

Run as separate files on node v22.22.0 and v24.21.0 before writing the key, 10/10 lines identical.

```
1) 3 [["H1","H2"],["H4","H5"],["H7"]]
2) 1 3
3) 3 ABC
4) [object Object]25080
5) { id: 'A', cena: 100 }
6) TypeError Reduce of empty array with no initial value
```

```
7) ids=H1,H%203
8) ids=H1,,H 3,
9) null Infinity
10) 80 NaN
```

Diagnosis: line 1: the end index of `slice` is excluded, so each batch has two ids and H3 and H6 are never checked. Line 2: `push(strony.map(...))` pushes one array that contains three arrays. Line 4: without an initial value `acc` starts as the object A, and `{...} + 250` is string concatenation. Line 5: with one element the callback never runs and the whole object comes back instead of 100. Line 6: an empty API response crashes the node. In the PR, line 8 sends empty slots and an unencoded space, line 9 turns "no offers" (`null`) into `Infinity`, which looks like a price, and one offer without `cena` makes the result `NaN`. (a) H3 and H6; `slice(i, i + ROZMIAR)` prints `1b) 3 [["H1","H2","H3"],["H4","H5","H6"],["H7"]]` (checked separately). (b) With `, 0`: `4b) 430 100 0` (checked separately). (c) `query2` matches only when no id is empty and none needs encoding; `najtansza2` matches only for a non-empty list where every offer has a price. A test on clean data passes for both versions, so the PR looks like a refactor until real form data or an empty API page arrives. Fix: `slice(i, i + ROZMIAR)`, `push(...strony.flatMap(s => s.items))`, `reduce((acc, x) => acc + Number(x.cena), 0)`, and in the PR keep `filter` + `encodeURIComponent` and an explicit empty-list case.

## Quiz

1. How many elements does `["a", "b", "c", "d"].slice(1, 3)` have, and which?
   **Key:** Two: `"b"` and `"c"`; index 3 only marks the end.
2. What does `[{ cena: 5 }].reduce((acc, x) => acc + x.cena)` return, and why is it not `5`?
   **Key:** The whole object `{ cena: 5 }`: without an initial value the first element is the accumulator, and with one element the callback never runs. `reduce(f, 0)` gives the number.
3. What does `` `ids=${["A", null, "B"]}` `` produce, and what does the partner API receive?
   **Key:** `ids=A,,B`: `join(",")` turns `null` into an empty slot, so the partner gets an empty id between the commas.

## Card

**Front:** What does `list.reduce((acc, x) => acc + x.cena)` return for a list with one object, and for an empty list?
**Back:** For one object: the object itself (the callback never runs). For an empty list: TypeError "Reduce of empty array with no initial value". `reduce(f, 0)` gives a number in both cases.

## Takeaway

REST/API work shows up in almost every automation job post, and in code it is mostly arrays: batches of ids for a bulk endpoint, pages to merge, a sum for the report. Asking "is the end included?" at every `slice` and "what does the accumulator start with?" at every `reduce` keeps rooms from going unchecked and keeps `[object Object]25080` out of a client's report.
