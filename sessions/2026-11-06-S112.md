# S112 - Functions: a "1:1 port" from Python to an n8n Code node

**Concept:** a JavaScript function takes arguments ONLY by position and returns ONE value, so lines ported from Python look the same and do something else. `return a, b` returns only `b` (comma operator), `f(x = 1)` is an assignment to a variable plus a positional argument, a missing argument is `undefined` instead of an error, `map` passes the callback the index and the array too, and a second `function` declaration with the same name wins in the whole file, even above itself.

**Story:** a glacier lagoon boat tour company in Jokulsarlon, Iceland, prices tours with a Python script. An AI assistant opened a PR "1:1 port of wycen.py to an n8n Code node, no logic change" and left the Python original in comments "for easy comparison". Two weeks later: the booking form shows only the harbour fee as the price, the winter fee applies to September bookings too, a family with two kids paid like three adults, and the daily report is all `NaN`.

## Round 1 - the pricing port, line by line (find the bug + predict the output; Python output in comments)

```js
// Port 1:1 z wycen.py do node `Code` w n8n: rejsy po lagunie "Lonsigling" w Jokulsarlon.
// Plik CommonJS bez "use strict" (jak kod w node Code). Oryginal z Pythona w komentarzach.

// def oplata(osoby): return osoby * 1000          # oplata portowa, sezon letni
function oplata(osoby) { return osoby * 1000; }

// def cena(osoby): return netto(osoby), oplata(osoby)
function cena(osoby) { return netto(osoby), oplata(osoby); }

// def netto(osoby, dzieci=0, rabat=None):
//     baza = osoby * 9000 + dzieci * 4500
//     if rabat is not None: baza = baza * (100 - rabat) // 100
//     return baza
function netto(osoby, dzieci = 0, rabat = undefined) {
  let baza = osoby * 9000 + dzieci * 4500;
  if (rabat !== undefined) baza = Math.floor((baza * (100 - rabat)) / 100);
  return baza;
}

console.log("1)", cena(2));                          // print(cena(2))
console.log("2)", netto(dzieci = 2, osoby = 1));     // print(netto(dzieci=2, osoby=1))
console.log("3)", netto(2, rabat = 10));             // print(netto(2, rabat=10))
console.log("4)", netto());                          // print(netto())
console.log("5)", ["2", "3", "10"].map(parseInt));   // print(list(map(int, ["2", "3", "10"])))
console.log("6)", [1, 2, 3].map(netto));             // print(list(map(netto, [1, 2, 3])))

// def oplata(osoby): return osoby * 1500          # od 1 pazdziernika: sezon zimowy
function oplata(osoby) { return osoby * 1500; }
console.log("7)", cena(2));                          // print(cena(2))
console.log("8)", typeof rabat, rabat, osoby);       // (w Pythonie: NameError, keyword nie tworzy zmiennej)
```

## Round 2 - four other lines from the same port (separate file)

```js

// handlery = [lambda: kod for kod in (429, 500, 503)]; print([h() for h in handlery])
const handlery = [];
for (const kod of [429, 500, 503]) handlery.push(() => kod);

console.log("10)", suma([9000, 4500]), suma(...[9000, 4500]));
```

## Verified

Run with node v22.23.4 and v24.21.0, each round as a separate file, before the key was written. The Python original was run with python3 3.13 and 3.14.

Python, for comparison: `(18000, 2000)` · `18000` · `16200` · `TypeError: missing 1 required positional argument` · `[2, 3, 10]` · `[9000, 18000, 27000]` · `(18000, 3000)` · `NameError` · `[503, 503, 503]` · `13500` · `14000` · `TypeError` (None * int).

Diagnosis: in JS the comma in `return a, b` is the comma operator, so `cena` returns only the fee, and `function` declarations are hoisted before the file runs, so the second `oplata` (winter rate) is already in force on line 1. JS has no keyword arguments: `dzieci = 2` is an assignment (a global in sloppy mode, a `ReferenceError` in strict mode/ESM) whose value goes in as argument 1, hence `netto(2, 1)` = 22500 and `netto(2, 10)` = 63000, and line 8 shows the leaked globals. A missing argument is `undefined`, so `netto()` silently gives `NaN`. `map` calls the callback with (element, index, array): `parseInt("3", 1)` is `NaN`, and `netto` gets the index as `dzieci` and the whole array as `rabat`. In Round 2 line 9 is better in JS than in Python (`const` in `for...of` makes a new binding per iteration), the rest parameter without spread gets one array and `0 + [9000, 4500]` concatenates text, `Math.max` has no `key=`, and a default parameter applies only to `undefined`, so `null` from JSON silently removes the discount.

Fix: `return [netto(osoby), oplata(osoby)]`, separate `oplataLato`/`oplataZima` instead of two declarations with one name, `function netto(osoby, { dzieci = 0, rabat } = {})` with a `Number.isFinite(osoby)` guard and `rabat != null`, calls `netto(1, { dzieci: 2 })`, `map(Number)` and `map((o) => netto(o))`. Checked: `fix: [18000,2000] 18000 16200 TypeError [2,3,10] [9000,18000,27000] [18000,3000]`.

## Quiz

1. What does a JS function with `return netto(osoby), oplata(osoby);` return, and how do you return both values? (Key: only `oplata(osoby)`; the comma evaluates both and returns the last. Return `[a, b]` or `{ a, b }`.)
2. Why is `netto(dzieci = 2, osoby = 1)` not a call with named arguments in JS, and how do you pass arguments "by name"? (Key: `dzieci = 2` is an assignment whose value `2` is passed by position. By name: one options object destructured in the signature, `function netto(osoby, { dzieci = 0, rabat } = {})`, called as `netto(1, { dzieci: 2 })`.)
3. When does the default value of `r = 10` apply: for `undefined`, for `null`, or both? (Key: only for `undefined`; `null` is a value and goes in as is.)

## Card

**Front:** `function f() { return 1, 2; }` - what does `f()` return?
**Back:** `2`. The comma is an operator: it evaluates both expressions and returns the last. JS returns ONE value; return two as `[a, b]` or `{ a, b }` (in Python `return 1, 2` is a tuple).

## Takeaway

Python is the third most common requirement in the AI integration job ads this log tracks, and in integration work it often shows up exactly like this: a working Python script has to move into an n8n Code node, and an AI assistant ports it "line by line". Whoever asks, for every call, "what do parameters 1, 2 and 3 receive, and how many values really come back?" stops that PR before a family with two kids pays like three adults.
