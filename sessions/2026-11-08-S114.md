# S114 - Errors: custom error classes, `name` vs `instanceof` in a RAG pipeline

**Concept:** `class X extends Error {}` gives you `message`, `stack` and `instanceof`, but it does NOT set `name` - that is still `"Error"`, inherited from `Error.prototype`. A `catch` that decides by `e.name` and a `catch` that decides by `instanceof` can therefore pick different branches for the same error, and at a boundary (a subclass, `structuredClone`, JSON inside an n8n item) the name and the class stop telling the truth.

**Story:** a fish festival in a small Icelandic town runs a RAG assistant in n8n. Visitors ask about the programme, parking and the menu; a Code node searches three indexes. Each failure has its own reaction: index offline -> fall back to a spare index, no results -> an honest "I don't know", 429 from the embeddings API -> retry. An AI assistant opened a PR "custom error classes instead of string comparisons, no logic change". Tests on two queries passed. On Saturday afternoon the map index went down and, instead of the fallback, the on-call engineer got paged.

## Round 1 - four queries, three custom error classes (predict the output)

```js
// Asystent RAG festiwalu "Fiskidagurinn" w Dalviku, node `Code` w n8n.
// PR od asystenta AI: "wlasne klasy bledow zamiast porownan tekstu, logika bez zmian".
class BladIndeksu extends Error {}
class BrakWynikow extends Error {
  constructor(zapytanie) {
    super(`brak wynikow dla: ${zapytanie}`);
    this.name = "BrakWynikow";
    this.zapytanie = zapytanie;
  }
}
class LimitEmbeddingow extends Error {
  name = "LimitEmbeddingow";
  constructor(ms) {
    super("429 z API embeddingow", { cause: { retryAfterMs: ms } });
  }
}

function szukaj(z) {
  if (z === "parking") throw new BladIndeksu("indeks 'mapa' offline");
  if (z === "fajerwerki") throw new BrakWynikow(z);
  if (z === "zupa") throw new LimitEmbeddingow(1200);
  return [`D-${z}`];
}

function obsluz(z) {
  try {
    return szukaj(z).join(",");
  } catch (e) {
    if (e.name === "BladIndeksu") return "FALLBACK: indeks zapasowy";
    if (e.name === "BrakWynikow") return "ODPOWIEDZ: nie wiem";
    if (e instanceof LimitEmbeddingow) return `RETRY za ${e.cause.retryAfterMs} ms`;
    return `ALARM: ${e}`;
  }
}

console.log("1)", obsluz("program"));
console.log("2)", obsluz("parking"));
console.log("3)", obsluz("fajerwerki"));
console.log("4)", obsluz("zupa"));
const e = new BladIndeksu("x");
console.log("5)", e.name, e.constructor.name, e instanceof BladIndeksu, e instanceof Error);
console.log("6)", String(new LimitEmbeddingow(5)), Object.keys(new LimitEmbeddingow(5)));
console.log("7)", JSON.stringify(new BrakWynikow("bilety")));
```

## Round 2 - the same classes after crossing a boundary (separate file)

```js
// Starcie 2 - osobny plik: te same klasy po przejsciu przez granice (podklasa, klon, item n8n).
class BrakWynikow extends Error {
  constructor(z) { super(`brak wynikow dla: ${z}`); this.name = "BrakWynikow"; }
}
class TimeoutIndeksu extends BrakWynikow {
  constructor(z) { super(z); this.message = `timeout: ${z}`; }
}
const t = new TimeoutIndeksu("rejsy");
console.log("8)", t.name, t instanceof BrakWynikow, t.message);

const klon = structuredClone(new BrakWynikow("bilety"));
console.log("9)", klon.name, klon instanceof BrakWynikow, klon.message);

const item = { json: { error: new BrakWynikow("parking") } };
const poNodzie = JSON.parse(JSON.stringify(item));
console.log("10)", poNodzie.json.error.name, poNodzie.json.error.message);

class ZlyBlad extends Error {
  constructor(z) { this.z = z; super(z); }
}
try { new ZlyBlad("mapa"); } catch (e) { console.log("11)", e.name, e.message); }

Promise.allSettled([Promise.reject(new TimeoutIndeksu("menu")), Promise.resolve(["D-1"])])
  .then((w) => console.log("12)", w.map((r) => r.status + ":" + (r.reason?.name ?? r.value)).join(" | ")));
```

## Verified

Both rounds run as separate files on node v22.23.4 and v24.21.0, identical output:

```text
1) D-program
2) ALARM: Error: indeks 'mapa' offline
3) ODPOWIEDZ: nie wiem
4) RETRY za 1200 ms
5) Error BladIndeksu true true
6) LimitEmbeddingow: 429 z API embeddingow [ 'name' ]
7) {"name":"BrakWynikow","zapytanie":"bilety"}
8) BrakWynikow true timeout: rejsy
9) Error false brak wynikow dla: bilety
```

Fix (base class sets the name from `new.target`, decisions use `instanceof`), run separately:

```js
// Poprawka (f): nazwa z klasy, decyzja po instanceof, nie po tekscie.
class BladRag extends Error {
  constructor(msg, opcje) { super(msg, opcje); this.name = new.target.name; }
}
class BladIndeksu extends BladRag {}
class BrakWynikow extends BladRag {}
class TimeoutIndeksu extends BrakWynikow {}
const a = new BladIndeksu("indeks 'mapa' offline");
const b = new TimeoutIndeksu("rejsy");
console.log("f)", a.name, b.name, b instanceof BrakWynikow, String(a));
```

```text

```

## Quiz

1. What is `new X().name` for `class X extends Error {}`, and why? **Key:** `"Error"`. `extends` does not set `name`, so the lookup reaches `Error.prototype.name`; `constructor.name` is `"X"` and `instanceof X` is true.
2. Why is `if (e.name === "Timeout")` a weaker test than `if (e instanceof Timeout)`, and when is the text all you have? **Key:** `name` is plain text: it can be unset, inherited from a parent class or overwritten, while `instanceof` checks the prototype chain. After a boundary (JSON, a clone, another process) the class does not survive, so an explicit `code` field (or the name you set yourself) is the only thing left.
3. What survives `JSON.stringify` of a custom error inside an n8n item, and what survives `structuredClone`? **Key:** JSON keeps only own enumerable fields (a `name` set with `this.name`, your own fields) and drops `message`/`stack`. `structuredClone` returns a plain `Error` with the `message`, but a non-standard name becomes `"Error"` and `instanceof` your class is false.

## Card

`class BladIndeksu extends Error {}` - what is `new BladIndeksu("x").name`, and what does it break? :: `"Error"`. `extends` does not set `name`, so a `catch` that checks `e.name === "BladIndeksu"` never matches. Set `this.name = new.target.name` in a base class or decide with `instanceof`.

## Takeaway

A RAG pipeline is not only retrieval but also what happens when retrieval fails. Checking where each error gets its `name` and what survives the item boundary is what keeps a "no logic change" PR from paging someone in the middle of a festival when one index goes down.
