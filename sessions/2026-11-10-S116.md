# S116 - Loops: where `continue` and `break` jump in an API pagination loop with retry

**Concept:** what `continue` does depends on the kind of loop. In a `for` loop the update expression (`page++`) runs first and only then the condition, so "retry this page" after a 429 actually skips it. In a `while` loop with the counter at the end of the body, and in `do...while`, `continue` jumps straight to the condition. `break` only leaves the innermost loop. And the condition is checked on every pass against LIVE data, so a shrinking queue or a missing `next` field changes how the loop runs without any error.

**Story:** a seal-watching centre imports tour bookings from a partner API every hour: pages with a 429 rate limit, dedupe, a message queue with acknowledgements, and confirmations sent in batches. An AI assistant opened a PR "shorter loops in the API client, no logic change". The one-page test passed. A week later the captain asks why the 2 pm tour sails with an empty deck when the partner says it sold four seats.

## Round 1 - pagination, dedupe, queue with ack, cursor (order of execution + predict the output)

```js
// Centrum fok "Selasetur" w Hvammstangi: import rezerwacji rejsow z API partnera.
// PR od asystenta AI: "krotsze petle w kliencie API, logika bez zmian".
const STRONY = { 1: ["R1", "R2"], 2: ["R3", "R4"], 3: ["R5", "R1", "R6"] };
let wywolania = 0;
function pobierz(strona) {                 // udawany GET /rezerwacje?strona=N
  wywolania++;
  if (strona === 2 && wywolania === 2) return { status: 429, items: [] };
  return { status: 200, items: STRONY[strona] || [] };
}

// PR: petla for zamiast while (bylo: wersja z linii 2)
const zebrane = [];
for (let strona = 1; strona <= 3; strona++) {
  const res = pobierz(strona);
  if (res.status === 429) continue;        // "ponow te sama strone"
  zebrane.push(...res.items);
}
console.log("1)", zebrane.join(","), "| wywolania:", wywolania);

wywolania = 0;                             // stara wersja sprzed PR, ten sam serwer
const stare = [];
let s = 1;
while (s <= 3) {
  const res = pobierz(s);
  if (res.status === 429) continue;
  stare.push(...res.items);
  s++;
}
console.log("2)", stare.join(","), "| wywolania:", wywolania);

const widziane = new Set(), nowe = [];     // PR: "stop na pierwszym duplikacie"
for (const strona of [STRONY[1], STRONY[3]]) {
  for (const id of strona) {
    if (widziane.has(id)) break;
    widziane.add(id);
    nowe.push(id);
  }
}
console.log("3)", nowe.join(","));

// kolejka wiadomosci partnera: GET ?offset=N&limit=2, a ack usuwa przetworzone z kolejki
const kolejka = ["W1", "W2", "W3", "W4", "W5"];
const przetworzone = [];
for (let offset = 0; offset < kolejka.length; offset += 2) {
  const partia = kolejka.slice(offset, offset + 2);
  przetworzone.push(...partia);
  for (const w of partia) kolejka.splice(kolejka.indexOf(w), 1);   // ack
}
console.log("4)", przetworzone.join(","), "| zostalo:", kolejka.join(","));

// paginacja kursorem: ostatnia strona NIE MA pola next; GET bez kursora = pierwsza strona
const KURSORY = { start: { items: ["K1"], next: "c2" }, c2: { items: ["K2"] } };
let kursor = "start", obroty = 0;
const k = [];
while (kursor !== null && obroty < 5) {    // bezpiecznik dopisany dopiero na tescie
  const res = KURSORY[kursor] || KURSORY.start;
  k.push(...res.items);
  kursor = res.next;
  obroty++;
}
console.log("5)", k.join(","), obroty, kursor);
```

## Diagram

```text
for (init; cond; page++) { ... continue; }   continue -> page++ -> cond   (page 2 skipped)
while (s <= 3) { ... continue; ... s++; }     continue -> cond            (same page again)
do { ... continue; } while (cond)             continue -> cond            (res = null -> exit, zero retries)

break          -> leaves the NEAREST loop (for...of over ids), the outer one keeps going
break partie   -> leaves the loop labelled `partie:` (both at once)

offset + ack:  [W1 W2 W3 W4 W5] off=0 -> W1,W2, ack -> [W3 W4 W5] off=2 -> W5, ack -> [W3 W4] off=4 STOP
cursor:        start -> c2 -> undefined (no next field) -> GET without cursor = start -> ... (only the guard stops it)
p++ < 3:       3 passes, p = 4          ++p < 3: 2 passes, p = 3
i <= 4, i += 2: i = 0, 2, 4 -> slice(4, 6) = [] (an empty batch goes to the API)
```

Fix (`page++` only after success, `continue` instead of `break` in dedupe, read the shrinking queue from the start, `while (cursor)`), run separately:

```js
const STRONY = { 1: ["R1", "R2"], 2: ["R3", "R4"], 3: ["R5", "R1", "R6"] };
let wywolania = 0;
function pobierz(strona) {
  wywolania++;
  if (strona === 2 && wywolania === 2) return { status: 429, items: [] };
  return { status: 200, items: STRONY[strona] || [] };
}
const zebrane = [], widziane = new Set();
for (let strona = 1; strona <= 3; ) {
  const res = pobierz(strona);
  if (res.status === 429) continue;        // strona++ tylko po sukcesie
  for (const id of res.items) { if (widziane.has(id)) continue; widziane.add(id); zebrane.push(id); }
  strona++;
}
console.log("f1)", zebrane.join(","), "| wywolania:", wywolania);
const kolejka = ["W1", "W2", "W3", "W4", "W5"], przetw = [];
while (kolejka.length > 0) { const partia = kolejka.slice(0, 2); przetw.push(...partia); kolejka.splice(0, partia.length); }
console.log("f2)", przetw.join(","), "| zostalo:", kolejka.length);
const KURSORY = { start: { items: ["K1"], next: "c2" }, c2: { items: ["K2"] } };
let kursor = "start"; const k = [];
while (kursor) { const r = KURSORY[kursor]; k.push(...r.items); kursor = r.next; }
console.log("f3)", k.join(","));
```

## Quiz

1. What runs after `continue` in `for (let i = 0; i < n; i++)`, and what runs after `continue` in `do { ... } while (w)`? **Key:** in `for`, `i++` first, then the condition, so the current item is skipped, not repeated. In `do...while`, the condition `w` right away; if it is false the loop ends without another pass.
2. How many passes does `while (p++ < 3)` make starting from `p = 0`, and what is `p` afterwards? **Key:** 3 passes, `p` is 4, because the increment also runs on the final, false check. `++p < 3` makes only 2 passes.
3. How do you stop both nested loops on the first 5xx, and why is a plain `break` not enough? **Key:** a label on the outer loop and `break label` (or `return` from a function). A plain `break` only ends the nearest loop.

## Card

A 429 retry via `continue` inside `for (let page = 1; page <= N; page++)`: which page does the next call fetch? :: The next one, not the same one: `continue` in a `for` loop runs `page++` before the condition, so the page after a 429 is lost. Retry in a loop where the counter only moves after success.

## Takeaway

In integration work, pagination with retry is the loop that matters most. Checking where `continue` jumps and where the counter moves in a PR like this catches the lost page of bookings before the partner asks why the tour sailed empty.
