# S124 - Arrays: a "shorter array operations in the RAG pipeline" PR where the context is built from batches instead of documents, the token budget becomes a string, the sources list loses the cited documents and chat history drops the newest question

**Concept:** an array method does what its arguments say, not what the PR description says. `[].concat(arrayOfArrays)` unpacks only ONE level of its argument (you get batches, not documents). `reduce` without an initial value starts from the first ELEMENT (object + number = string). `splice` returns the removed items AND takes them out of the array. `join` on an array of arrays inserts commas. In `slice(i, 3)` the second argument is the end index, not a length. `length = MAX` truncates from the end (the newest item disappears) or appends holes.

**Story:** a puffin-watching site runs a RAG assistant for tourists. An n8n `Code` node queries two indexes (guide and FAQ), merges the results, checks a token budget, picks the two best documents for the context and lists the sources under the answer. A second file splits the guide into windows of three sentences and trims chat history to four messages. An AI assistant opened a PR "shorter array operations in the RAG pipeline, no logic changes" and left the pre-PR version in comments.

## Round 1 - merging results, budget, top-k and context (predict the output + code review)

```js
// Punkt obserwacji maskonurow "Hafnarholmi" w Borgarfjordur eystri: asystent RAG odpowiada turystom.
// Node Code w n8n sklada kontekst z dwoch indeksow (przewodnik + FAQ). PR od asystenta AI:
// "krotsze operacje na tablicach w pipeline RAG, logika bez zmian". W komentarzach wersja sprzed PR.
const z = (id, score, tokeny, ...zdania) => ({ id, score, tokeny, zdania });
const WYNIKI = [
  [z("d1", 0.91, 120, "Maskonury sa od kwietnia", "do sierpnia."), z("d2", 0.40, 40, "Parking jest bezplatny.")],
  [z("d3", 0.88, 60, "Platforma jest otwarta cala dobe.")],
];

const wszystkie = [].concat(WYNIKI);                       // przed PR: [].concat(...WYNIKI)
console.log("1)", wszystkie.length, wszystkie.map(d => d.id).join(","));

const DOCS = WYNIKI.flat();
const suma = DOCS.reduce((s, d) => s + d.tokeny);          // przed PR: DOCS.reduce((s, d) => s + d.tokeny, 0)
console.log("2)", suma, suma <= 300);

const posortowane = DOCS.toSorted((a, b) => b.score - a.score);
const top = posortowane.splice(0, 2);                      // przed PR: posortowane.slice(0, 2)
const kontekst = top.map(d => d.zdania).join("\n");        // przed PR: top.map(d => d.zdania.join(" ")).join("\n")
console.log("3)", JSON.stringify(kontekst));
console.log("4)", "top:", top.map(d => d.id).join(","), "| zrodla pod odpowiedzia:", posortowane.map(d => d.id).join(","));
```

## Quiz

1. What does `[].concat([[1, 2], [3]])` return, and what does `[].concat(...[[1, 2], [3]])` return? **Key:** `[[1, 2], [3]]` (one argument, unpacked one level) and `[1, 2, 3]` (two arguments, each unpacked).
2. Where does `s` start in `docs.reduce((s, d) => s + d.tokens)` without a second argument, and what happens with an array of objects? **Key:** at the first element, and the loop starts at the second. `s` is an object, so `s + d.tokens` concatenates the string `"[object Object]..."` and the first document's tokens are lost. Always pass `0`.
3. What is left in `t = [1, 2, 3, 4, 5]` after `t.length = 3`, and after `t.length = 7`? **Key:** `[1, 2, 3]` (truncated from the end) and `[1, 2, 3, 4, 5, <2 empty items>]` (holes that `map`/`forEach` skip and `for...of` visits as `undefined`).

## Card

RAG pipeline on arrays: what do `[].concat(arrayOfArrays)`, `reduce` without an initial value, `splice(0, k)` and `history.length = MAX` do? :: `concat` unpacks one level of its argument (use `concat(...x)` or `flat()`); `reduce` without `0` starts from the first element (object + number = string); `splice` removes the items from the array (use `slice`); `length = MAX` truncates from the end or appends holes (use `slice(-MAX)`).

## Takeaway

In code, RAG is mostly arrays: merging results from several indexes, a token budget, top-k, a sources list, chunking windows and chat history. None of the six changes in this PR threw an error when it ran. The model got a worse context and the answer looked just as confident. Ask three questions for each method: what each argument means, what it returns, and whether the array looks the same afterwards.
