# S129 - Operators: an "unnecessary parentheses removed from the reranker, no logic changes" PR that scores 1.4 instead of 1.8, lets a 0.41 document into the context and drops the prompt header

**Concept:** operator precedence decides how an expression is GROUPED, not the order in which it RUNS. Operands are always evaluated left to right, but once a PR removes "unnecessary" parentheses, `*` binds before `+`, `!` before `<`, `*` before `??`, and `+` glues text together before `>` and `?:` compare anything. `??` next to `||` without parentheses is not even valid syntax.

**Story:** a lava exhibition centre in South Iceland runs a RAG assistant in an n8n `Code` node. It combines keyword (bm25) and vector scores, drops documents below a threshold and always adds the pinned safety rules. An AI assistant opened a PR: "unnecessary parentheses removed from the reranker, shorter, no logic changes". The single-document test passed.

## Quiz

1. In `f() + g() * h()`, which function is called first, and why is the result not `(f() + g()) * h()`? **Key:** f, then g, then h: operands are evaluated left to right. The precedence of `*` only decides the grouping: `f() + (g() * h())`.
2. What does `!x < 0.5` give for `x = 0.41`, and how do you write "x is not less than 0.5"? **Key:** `!0.41` is `false`, `false < 0.5` is `0 < 0.5`, so `true`. Correct: `!(x < 0.5)` or `x >= 0.5`.
3. Why does `"Pewnosc: " + s > 0.5 ? "wysoka" : "niska"` always give `"niska"`, and how do you fix it? **Key:** `+` binds tighter than `>`, and `>` tighter than `?:`, so the string "Pewnosc: 0.82" is compared with 0.5 (NaN, false). Parenthesise the ternary or use a template literal.

## Card

How does the engine read `a() + b() * c()`, `!x < p`, `k ?? 2 * 2` and `"t" + n > 2 ? A : B`? :: Precedence groups them as `a() + (b()*c())`, `(!x) < p`, `k ?? (2*2)`, `(("t"+n) > 2) ? A : B`; operands still run left to right (a, b, c). When a PR removes parentheses, put them back in your head by precedence and compare with the original. `??` next to `||`/`&&` without parentheses is a SyntaxError.

## Takeaway

RAG rerankers and context builders are dozens of short expressions with weights, thresholds and text. This PR threw no error, yet the model got a different ranking, a document below the threshold, the wrong page in the citation and a prompt without its header. When reviewing a diff that "only removed parentheses", always put them back in your head.
