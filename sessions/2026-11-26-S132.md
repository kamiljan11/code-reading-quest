# S132 - Reading a diff: a "shorter checks in the webhook receiver, no logic changes" PR that turns the event cursor into NaN, accepts an empty webhook and makes the booking API look up "anna lodge"

**Concept:** a "shorter equivalent" is a refactor only if it gives the same result for EVERY input that arrives over the network. `Math.max` turns ISO strings into numbers (NaN, and -Infinity for an empty list), `!body` does not reject an empty object, `encodeURI` leaves `+`, `&` and `=` inside a value, `replace` with a string removes only the first occurrence, and `includes` on a string looks for a substring, not a list element.

**Story:** a hotel by the Dettifoss canyon receives payments through a provider that sends webhooks with a batch of events. The receiver stores a cursor (time of the latest event), rejects empty batches and, for each payment, asks the booking API for the guest by email and the partner's booking reference. An AI assistant opened a PR: "shorter checks in the webhook receiver, no logic changes". The tests used one clean webhook with one event, and they passed.

## Quiz

1. Why does `Math.max(...list.map(z => z.ts))` with ISO dates give NaN, and what does `Math.max()` return with no arguments? **Key:** `Math.max` converts every argument to a number and an ISO string is NaN for `Number`, so the result is NaN. With no arguments it returns -Infinity. ISO strings can be compared with `>` (lexicographically) or converted with `Date.parse`.
2. What is the difference between `encodeURI` and `encodeURIComponent` when building a query string? **Key:** `encodeURI` encodes a whole URL and keeps characters that have a meaning in it (`+`, `&`, `=`, `?`, `/`, `@`). `encodeURIComponent` encodes a single value including those characters. Always encode a parameter value with `encodeURIComponent` or `URLSearchParams`.
3. What does `"A-B-C".replace("-", "")` return, and how do you remove every dash? **Key:** `AB-C`, because `replace` with a string replaces only the first occurrence. All of them: `replaceAll("-", "")`, `replace(/-/g, "")` or `split("-").join("")`.

## Card

Why is `encodeURI(value)` in a query string a bug, and what should you use instead? :: `encodeURI` does not encode `+ & = ?`, so `+` is read as a space and `&` splits the value into a new parameter. For a parameter value: `encodeURIComponent` or `URLSearchParams`.

## Takeaway

A webhook receiver and an API client are where data from someone else's system arrives with odd edges: an empty batch, a plus sign in an email, an ampersand in a booking reference. A PR full of "shorter equivalents" passes tests on clean data and, in production, loses events and looks up the wrong guest. In review, ask: for which input do these two versions differ?
