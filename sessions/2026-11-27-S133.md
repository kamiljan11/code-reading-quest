# S133 - Functions: a "1:1 port from przejazdzki.py, no logic changes" PR that counts the daily revenue twice, crashes the SMS reminders and logs only one of three confirmations

**Concept:** in Python an assignment inside a function creates a LOCAL variable, while in JS without `let`/`const` it overwrites the outer one. `total += f()` reads `total` BEFORE `f` runs. The default `(g = g)` reads its own parameter in the temporal dead zone (ReferenceError). A `@log` decorator runs at `def` time and rebinds the name, while a JS `function` declaration is hoisted and called without the wrapper.

**Story:** an Icelandic horse riding stable books group rides in n8n. The logic lived for years in a Python script: group sum, adding to the daily revenue, SMS reminders and a decorator that logs every booking confirmation. An AI assistant moved it to an n8n `Code` node and opened a PR: "1:1 port from przejazdzki.py, no logic changes". The test only checked that the first group had the right sum, and it passed.

## Round 1 - bookkeeping and reminders after the PR (order of execution)

```js
// Stajnia koni islandzkich "Ishestar" w Hafnarfjordur: node Code w n8n, ksiegowanie przejazdzek.
// PR od asystenta AI: "port 1:1 z przejazdzki.py, logika bez zmian".
let obrot = 0; // Python: obrot = 0 na poziomie modulu

// Python: def suma_grupy(grupa): obrot = 0 ... (w Pythonie to zmienna LOKALNA funkcji)
function sumaGrupy(grupa) {
  obrot = 0;
  for (const cena of grupa) obrot += cena;
  return obrot;
}

// Python: global obrot; w = suma_grupy(grupa); obrot += w
function zaksieguj(grupa) {
  const w = sumaGrupy(grupa);
  obrot += w;
  return w;
}

// Python: global obrot; obrot += suma_grupy(grupa)
function zaksiegujKrotko(grupa) {
  obrot += sumaGrupy(grupa);
  return obrot;
}

console.log("1)", zaksieguj([12000, 9000]), obrot);
console.log("2)", zaksieguj([15000]), obrot);
console.log("3)", zaksiegujKrotko([8000]), obrot);

// Python: przypomnienia = [lambda g=g: f"SMS do {g}" for g in goscie]
const goscie = ["Anna", "Bjorn"];
const przypomnienia = goscie.map(g => (g = g) => `SMS do ${g}`);
try {
  console.log("4)", przypomnienia.map(f => f()).join(" | "));
} catch (e) {
  console.log("4)", e.constructor.name + ":", e.message);
}
```

## Round 2 - the `@loguj` decorator, same PR (separate file)

```js
// Starcie 2 - osobny plik: ten sam PR, dekorator @loguj z przejazdzki.py.
const log = [];
function loguj(fn) {
  log.push("rejestracja " + fn.name);
  return function (...args) {
    log.push("wywolanie " + fn.name + " " + args[0]);
    return fn(...args);
  };
}

// Python: @loguj nad def potwierdz(rez) na gorze pliku, wywolania nizej
console.log("5)", potwierdz("R1"), log.length);
function potwierdz(rez) {
  return "OK " + rez;
}
const potwierdzZLogiem = loguj(potwierdz);
console.log("6)", potwierdz("R2"), potwierdzZLogiem("R3"));
console.log("7)", log.join(" ; "));
```

**Question:** predict all 7 lines (each round is a separate file). For line 3) order the steps: read `obrot`, call `sumaGrupy`, write `obrot`. For round 2, order the entries in `log`. For every line, say what the Python original printed.

## Quiz

1. What does `obrot = 0` inside a function do in Python, and what does the same line without `let` do in JS when there is an outer `let obrot`? **Key:** Python creates a new local variable (without `global`), the module one stays untouched. JS overwrites the outer `obrot`. A local in JS is `let obrot = 0`.
2. In what order does JS run `x += f()` when `f` itself changes `x`? **Key:** read old `x`, call `f`, write old `x` + result. The change `f` made to `x` is lost.
3. Why does the Python idiom `lambda g=g: ...` rewritten as `(g = g) => ...` throw a ReferenceError? **Key:** defaults are evaluated in the parameter scope, so the right-hand `g` is the same, not yet initialized parameter (TDZ). In JS a closure is enough: `goscie.map(g => () => ...)`.

## Spaced repetition card

**Q:** What happens in JS when you write `x += f()` and `f()` itself changes `x`?
**A:** JS reads the old `x`, then calls `f`, then writes old `x` + the result. The change `f` made to `x` is overwritten.

## Takeaway

Porting a Python script to n8n carries the syntax over 1:1, but not variable scope and not the moment a decorator runs. In a port review, ask: which variable does this assignment hit, and when was this function wrapped?
